## 🎀 About this site

This is my personal portfolio: a hot pink, sparkly corner of the internet where I share my work, projects and credentials. It is built with plain HTML, CSS and JavaScript, with no frameworks and no build step.

## 💅 What's inside

- 🖥️ **Animated terminal intro** that types out who I am
- 🎭 **"Pick a Mariyum" tabs** to switch between engineer, data learner and chemistry fan
- 💼 **Work experience** as a System Administrator (Cloud & Data Operations) at Kyndryl
- 🃏 **Project cards** including Block by Block, Tracehound, Cloud Cost to User Impact Analyzer and an AI-based timetable scheduler
- 🎓 **Credentials** with my education, JETIR publications and Fortinet certifications
- 📈 **Learning progress bars** that fill as you scroll
- ✨ **Sparkles** that follow your cursor (and respect reduced-motion settings)
- 🌙 **Light and dark mode**, and it works on phones too

## 🛠️ Built with

|---|---|
| 🎨 | HTML5 and CSS3 (custom properties, grid, flexbox, 3D flip cards) |

## 🚀 Run it locally

```bash
git clone https://github.com/Mariyum008/mariyum008.github.io.git
cd mariyum008.github.io
open index.html   # or just double-click the file
```

## 🌸 Make it yours

Everything lives in one file, `index.html`. Change the text, swap the colors in the `:root` section at the top, or add your own project cards.
